# ระบบประมวลผลเกรด 969-042G4

เปิดไฟล์ `grading.html` แล้วใส่รหัสผ่านเพื่อเข้าใช้งาน

## โครงสร้าง
- `grading.html` · `css/grading.css` · `js/grading.js` : หน้าเว็บและโปรแกรม (ไม่มีข้อมูลนักศึกษา)
- `data/grades.enc.js` : รายชื่อนักศึกษา (และคะแนน) **ที่เข้ารหัสแล้ว** เปิดอ่านไม่ได้ถ้าไม่มีรหัสผ่าน

## การบันทึก
- แก้คะแนนแล้วระบบเข้ารหัสและบันทึกในเบราว์เซอร์เครื่องนั้นอัตโนมัติ รีเฟรชแล้วข้อมูลไม่หาย
- ช่องว่าง = ยังไม่ได้กรอก (ไม่ใช่ 0) · ถ้าได้ 0 คะแนนจริง ให้พิมพ์ 0
- ข้อมูลที่บันทึกอยู่ในเครื่องที่แก้เท่านั้น ถ้าจะให้เครื่องอื่น/เว็บออนไลน์เห็นข้อมูลล่าสุด:
  กด **ดาวน์โหลดไฟล์สำรอง** แล้วนำ `grades.enc.js` ที่ได้ไปแทนที่ไฟล์ใน `data/`

## ลืมรหัสผ่าน
- หน้าใส่รหัสมีปุ่ม **ลืมรหัสผ่าน?** : ใส่ **รหัสกู้คืน** (24 ตัวอักษร) แล้วตั้งรหัสผ่านใหม่ ข้อมูลไม่หาย
- รหัสกู้คืนต้องจดเก็บไว้เอง (ระบบไม่เก็บ/ไม่ส่งอีเมลให้) ถ้าลืมทั้งรหัสผ่านและรหัสกู้คืน กู้ข้อมูลไม่ได้
- สร้างรหัสกู้คืนชุดใหม่ได้ที่ปุ่ม 🛟 (ชุดเก่าจะใช้ไม่ได้ และต้องดาวน์โหลดไฟล์สำรองไปแทนที่ใน `data/`)

## ข้อควรระวัง
- ไม่มีไฟล์ต้นฉบับอื่นสำรองคะแนน: ล้างข้อมูลเบราว์เซอร์ (cache/ข้อมูลเว็บไซต์) จะทำให้คะแนนที่ยังไม่ได้สำรองหาย
  ให้กด **ดาวน์โหลดไฟล์สำรอง** และ **ส่งออก CSV** เก็บไว้เป็นระยะ
- ไฟล์ CSV ที่ส่งออกไม่ได้เข้ารหัส เก็บให้ปลอดภัย
- ห้ามนำข้อมูลคะแนนแบบไม่เข้ารหัสขึ้นเว็บหรือ GitHub
